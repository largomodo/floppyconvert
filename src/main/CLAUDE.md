# main/

## Subdirectories

| Directory    | What                                                                  | When to read                                                          |
| ------------ | --------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `java/`      | Production Java source root (Maven layout)                            | Editing source code; descend to `com/largomodo/floppyconvert/`        |
| `resources/` | Logback config, Picocli resource bundle, GraalVM reflection metadata  | Modifying logging, CLI metadata, or native-image reflection registrations |
