# core/

Orchestration layer: pipeline coordination, dependency-inversion boundary, packing, and workspace lifecycle.

## Files

| File                       | What                                                                                                                                                                                                                                                                                                                                                                                                  | When to read                                                                                                                                       |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `README.md`                | ConversionFacade dependency-inversion rationale, god-method decomposition rules, per-layout DOS name validation, package invariants                                                                                                                                                                                                                                                                  | Understanding facade-pattern decisions, reviewing decomposition tradeoffs, troubleshooting architectural boundaries                                |
| `ConversionFacade.java`    | Interface for ROM conversion: `splitRom()` and `write()`; abstracts `RomSplitter` and `FloppyImageWriter`                                                                                                                                                                                                                                                                                              | Adding alternative conversion implementations, understanding facade pattern                                                                        |
| `ConversionObserver.java`  | Observer interface for batch-processing events                                                                                                                                                                                                                                                                                                                                                       | Adding progress monitoring or telemetry                                                                                                            |
| `DiskTemplateFactory.java` | Interface for floppy disk template providers; method takes `targetImage`                                                                                                                                                                                                                                                                                                                              | Adding alternative template sources, understanding template abstraction                                                                            |
| `FloppyType.java`          | Enum for 720KB/1.44MB/1.6MB floppy formats: geometry (tracks/heads/sectorsPerTrack/rootEntryCount/mediaDescriptor/sectorsPerFat/sectorsPerCluster), capacity limits, `bestFit(long)` / `bestFit(long, FloppyType)` selection, `minimumForFormat(CopierFormat)` for firmware-driven floor constraints, `getTotalCapacity()` for dynamic image sizing; declaration order must match ascending capacity (ordinal comparison used for floor clamping) | Adding new disk format, debugging capacity errors, understanding FAT12 geometry parameters, understanding GD3 minimum-type constraint              |
| `RomPartComparator.java`   | Universal sort comparator for ROM split parts (numeric extensions, UFO `.gm` extensions with numeric prefix, alphanumeric)                                                                                                                                                                                                                                                                            | Debugging sort order, extending to new naming patterns                                                                                             |
| `RomPartNormalizer.java`   | Stateless utility for ROM part filename sanitization and metadata generation; calls `RomPartMetadata.of(...)` at the producer boundary, which internally validates via `DosName.of()`                                                                                                                                                                                                                 | Debugging filename sanitization or shell-compatibility issues, tracing DosName producer wiring                                                     |
| `RomProcessor.java`        | Pipeline orchestrator with constructor DI; `processRom(romFile, outputBaseDir, uniqueSuffix, format, singleFileMode)`: `singleFileMode=true` writes `.img` directly to `outputBaseDir`, `singleFileMode=false` creates `outputBaseDir/romName/` subdirectory; decomposed into 7 helper methods; coordinates `DiskPacker` / `ConversionFacade` / `DiskTemplateFactory` / `RomPartNormalizer` via `ConversionWorkspace` | Changing disk-spanning logic, debugging DOS name collisions, modifying pipeline flow, understanding `singleFileMode` output placement              |
