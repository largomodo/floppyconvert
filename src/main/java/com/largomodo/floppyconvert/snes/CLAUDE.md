# snes/

SNES ROM parsing, hardware validation, GD3 interleaving, and immutable domain records.

## Files

| File                              | What                                                                                                                                                                                                                                                                                              | When to read                                                                                                                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `README.md`                       | Staged pipeline (read → validate → interleave → split → write), data flow diagrams, immutability/factory rationale, hardware-validation invariants, GD3 force-split rule, UFO irregular-chunks rule, ucon64 binary-compat invariants                                                              | Understanding SNES conversion architecture, reviewing design decisions, troubleshooting pipeline issues                                                   |
| `SnesConstants.java`              | Shared constants: `MBIT = 131072` (1 Mbit = 128 KB)                                                                                                                                                                                                                                                | Adding new SNES-related constants, understanding size calculations                                                                                        |
| `RomType.java`                    | Enum for memory-map types: LoROM (header @ `0x7FB0`), HiROM (`0xFFB0`), ExHiROM (`0x40FFB0`)                                                                                                                                                                                                       | Adding new ROM types, understanding header location mapping                                                                                               |
| `SnesRom.java`                    | Immutable record with `RomType`, SRAM size, DSP flag, title, checksum fields, `rawData`; `isHiRom()` helper; compact constructor enforces `(checksum + complement) & 0xFFFF == 0xFFFF` arithmetic invariant                                                                                        | Understanding ROM metadata, debugging header parsing, validating ROM integrity, understanding checksum enforcement                                        |
| `SnesRomReader.java`              | Parser: strips 512-byte copier header, probes `0x7FB0`/`0xFFB0`/`0x40FFB0`, weighted scoring for type detection, validates `checksum + complement = 0xFFFF`, Map Mode `0x25` for ExHiROM                                                                                                            | Debugging ROM detection failures, understanding scoring weights, adding new header locations                                                              |
| `HardwareValidator.java`          | Interface: `validate(SnesRom, CopierFormat) throws UnsupportedHardwareException`                                                                                                                                                                                                                  | Adding alternative validation strategies, understanding validation abstraction                                                                            |
| `UfoHardwareValidator.java`       | Enforces UFO ceilings: HiROM ≤32 Mbit, LoROM ≤36 Mbit (max 9 parts at 4 Mbit chunks)                                                                                                                                                                                                              | Debugging UFO compatibility, understanding UFO constraints                                                                                                |
| `Gd3HardwareValidator.java`       | Enforces GD3 ceilings: standard HiROM/LoROM ≤32 Mbit; ExHiROM ≤64 Mbit                                                                                                                                                                                                                            | Debugging GD3 compatibility, understanding ExHiROM support                                                                                                |
| `UnsupportedHardwareException.java` | RuntimeException for hardware-constraint violations                                                                                                                                                                                                                                              | Understanding validation error handling                                                                                                                   |
| `SpecialCaseRegistry.java`        | Static utility: `isTalesOfPhantasia(rom)` (maker `0x36` + title), `isDaiKaijuMonogatari2(rom)` (maker `0x18` + title); games requiring non-standard GD3 header values per ucon64 `snes.c:955-1010`                                                                                                  | Understanding game-specific quirks, debugging header overrides, adding new special cases                                                                  |
| `SnesInterleaver.java`            | GD3 HiROM/ExHiROM interleaver: pads to 8 Mbit with `0x00`, global block swapping (not per-chunk), `n = size/2` partitions output; upper 32 KB of each 64 KB block → first half, lower 32 KB → second half; ExHiROM split-interleaving (base 32 Mbit + expansion separately); LoROM bypass; non-destructive | Debugging GD3 interleaving, understanding global vs per-chunk algorithm, troubleshooting padding, understanding ExHiROM split-interleaving                |
