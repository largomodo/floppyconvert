# snes/ (tests)

## Files

| File                              | What                                                                                                                                                                                                                                                                                                                                                                                            | When to read                                                                                                                                            |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RomTypeTest.java`                | Memory-map type functionality                                                                                                                                                                                                                                                                                                                                                                  | Verifying `RomType` behavior                                                                                                                            |
| `SnesRomTest.java`                | `SnesRom` record metadata validation, immutability                                                                                                                                                                                                                                                                                                                                              | Verifying record behavior                                                                                                                               |
| `SnesRomReaderTest.java`          | Property-based: header location probing, checksum validation, type detection; specific cases for 32 Mbit HiROM with SRAM (`SYNHI32T8`) and 4 Mbit LoROM (`SYNLO4T0`)                                                                                                                                                                                                                            | Verifying ROM detection logic, debugging type-scoring algorithm                                                                                         |
| `HardwareValidatorTest.java`      | Property-based: UFO HiROM 32 Mbit boundary, UFO LoROM 36 Mbit boundary, GD3 ExHiROM 64 Mbit boundary, GD3 standard 32 Mbit boundary; synthetic ROMs at boundaries                                                                                                                                                                                                                                | Verifying hardware validators, adding constraint test cases                                                                                              |
| `SpecialCaseRegistryTest.java`    | Tales of Phantasia / Dai Kaiju Monogatari 2 detection, wrong maker/title combos, case sensitivity                                                                                                                                                                                                                                                                                              | Verifying game detection, adding new special-case tests                                                                                                  |
| `SnesInterleaverTest.java`        | Property-based GD3 interleaver tests: byte-sum equality / all-bytes-present, block-pair location correctness, edge cases (8/16/24 Mbit), ExHiROM split-interleave (40-64 Mbit), LoROM bypass                                                                                                                                                                                                    | Verifying global interleaving, cross-chunk block mapping, ExHiROM split-interleave, LoROM bypass                                                         |

## Subdirectories

| Directory      | What                                                                                                  | When to read                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `header/`      | Per-format header generator + SRAM encoder unit and property tests                                    | Verifying header bytes, SRAM encoding, factory selection                                    |
| `generators/`  | Synthetic ROM generation utilities (`SyntheticRomFactory`, `RomDataGenerator`) and their tests        | Adding synthetic ROM variants, debugging ROM generation, extending property-based test data |
